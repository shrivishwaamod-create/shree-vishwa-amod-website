## Publish using GitHub
1. Download and keep a backup of the current repository first.
2. Extract this ZIP on your computer.
3. Open the GitHub repository and upload the contents of this folder to the repository root. `index.html` must be at the root level, not nested in another folder.
4. Commit the changes to the `main` branch.
5. Cloudflare should deploy automatically if its existing GitHub integration is connected. Wait for deployment to finish, then test the website on desktop and mobile.

Do not change DNS or nameservers for this content update.
